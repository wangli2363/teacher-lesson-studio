# 课例工坊 · 教师制作台

面向课堂的静态互动课件制作台。先在欢迎页描述教学需求，进入工作台配置内容、预览试教，然后直接导出离线 HTML。

- 六个场景：水果店、文具店、身高测量、食谱厨房、运动测量、超市比价。
- 五步课堂：情境引入、概念认识、情境迁移、拓展例子、配套练习。
- 无账号、无后端、固定题库，不保存学生作答。
- 导出后仍可修改配置；再次导出使用当前内容。

`index.html` 为完整单文件网页，包含页面样式、交互代码、场景内容及题库。
双击可本地使用，亦可部署到 GitHub Pages。页面底部保留上一版小数与分数模板入口。

在线访问：[打开教师制作台](https://wangli2363.github.io/teacher-lesson-studio/)

## 欢迎页

输入教学需求或点选示例，点击“开始制作”带入现有六场景的配置。支持年级、人数、时长、5–10道练习、水平、题型与表征。教学重点写入教师提醒，完整目标可在工作台继续调整。未填写内容显示默认值；不支持的主题或超限配置会提示修改。

这是本地关键词匹配与固定模板组合，不调用实时模型或生成新题。可以直接进入制作台或打开草稿；返回欢迎页后“继续编辑”保留配置，重新提交需求开始新配置。
